# 支持范围

| 项目 | 要求 |
| --- | --- |
| 宿主 | 带 `com.astraisland.HOST_PROTOCOL` 元信息的星流正式／调试包；独立星河岛应用已停止发布，1.2.0 起不再作为宿主 |
| 接入库 | 1.3.0（通信版本 6）。1.2.0 仍能连接，只是用不上 1.3.0 新增的内容；1.1.x 和更旧的库才会认已停发的独立包，现在不再认 |
| 通信版本 | 6，照常接受 5：宿主是 5 时，回复输入条、能拖的进度条和本版新增的显示内容不出现，其余照常 |
| 客户端最低系统 | Android 8.0／API 26 |
| 岛最低系统 | Android 15／API 35；安卓 13、14 上星流不运行星河岛，连接停在等待 |
| 已验证设备 | 一加Ace 6，ColorOS 16 |
| 接入用户空间 | 主用户空间 |

其他机型暂未验证。

## 连接与恢复

- 等待 `onReadyChanged(true)` 后投送内容。
- `connect()` 发起连接或重新连接；`disconnect()` 结束本连接的内容。
- 重新连接后用 `listMine()` 核对，再补投当前业务内容。
- 来源负责自己的任务状态，不将事件回调作为业务完成的唯一依据。
- `start`／`update`／`end` 合计每来源每秒最多10次，自动展开间隔至少10秒，重新连接不会重置限制。
- 连接失效后调用 `connect()` 恢复。

## 正式构建

来源应用可开启代码混淆，无需添加保留全部客户端类的规则。发布前验证连接、更新、按钮、回复、拖动进度、结束与锁屏显示。
