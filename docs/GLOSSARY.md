# 星河岛

星河岛把来源应用的消息、播放和持续任务等内容，放到统一的显示区域中。下面的名称用于界面、设计说明与开发文档。

## 显示区域

**主岛**：当前主要内容的显示区域，可以收起，也可以展开。


**副岛**：主岛两侧承载其他内容的小圆形区域。


**胶囊**：主岛收起后的形态。


**展开卡片**：主岛展开后显示更多内容和操作的形态。


## 内容与来源

**内容项**：星河岛接收的一件信息，例如一条消息、一次播放或一个计时任务。


**来源应用**：提供内容项并负责其实际业务操作的应用。


**实时活动**：外卖、打车、导航等持续更新的内容种类，也是设置里的开关名称。


**身份区**：胶囊中表示来源或身份的图标、头像和名称区域。


**信息区**：胶囊中显示正文、歌词、时间或进度的区域。


**音乐卡片**：展示播放器内容、进度和控制操作的展开卡片。


**大图卡片**：以来源实际提供的大图为主要内容的展开卡片。


**自绘卡片**：由来源应用提供完整图片和操作区域的展开卡片。
