# 星河岛接入协议规范（通信版本 5）

本规范对应星河岛1.1、接入库1.1.0和通信版本5。用法见[接入指南](INTEGRATION.md)。

## 一、接入方身份

星河岛允许外部 App 把自己的「内容项」送上岛。实际的准入模型如实说明如下，只有一道硬门槛，其余是用户开关与配额：

1. **声明权限即可投送。** 在 `AndroidManifest.xml` 中申请星河岛定义的权限：
   ```xml
   <uses-permission android:name="com.astraisland.permission.PUBLISH_ACTIVITY" />
   ```
   该权限由星河岛安装包定义（`protectionLevel="normal"`），不弹授权框，任何声明了它的 App 都能投送。客户端未发现星河岛时进入 `NOT_INSTALLED`，没有会话的调用返回 `RESULT_NOT_CONNECTED`；`RESULT_NO_PERMISSION` 表示已到达服务端但来源没有该权限。

2. **用户可以关掉你。** 来源第一次绑定成功后会出现在星河岛设置页的「来源管理」列表里（默认启用），用户可以单独关掉任何一个来源。关掉后你的投送返回 `RESULT_SOURCE_DISABLED`，已经在岛上的内容项立刻撤下（回传 `onEndedBySystem`），连接不断开。设置页「显示内容」开关（音乐 / 消息 / 计时与闹钟 / 实时活动，自定义种类归实时活动）同样生效，返回 `RESULT_KIND_DISABLED`。

3. **配额与频率：**
   - 同时最多 3 个内容项（收尾画面不占）。第 4 个新内容项返回 `RESULT_QUOTA_EXCEEDED`；已存在内容项的整份替换不受影响。
   - `start` / `update` / `end` 合计每秒最多 10 次，超出返回 `RESULT_RATE_LIMITED` 并丢弃；同一内容项 250 毫秒内的多次更新只上屏最后一次（不同内容项互不覆盖）。
   - 外部来源的自动展开（`alertOnStart` / `alertOnUpdate`）每来源 10 秒最多一次，冷却期内提醒标记被岛清掉，内容项照常上屏。

普通 `end` 与重连后的频率、冷却均按来源统一执行；`endAll()` 仅作幂等清理，不展示收尾内容。回调在后台以单向通信发出，不等待来源执行完成；每连接最多32个待发送回调，超出或发送异常使该连接失效。来源通过 `connect()` 重新连接并同步业务。

### 注册与绑定

1. 接入方发定向广播 `com.astraisland.action.REGISTER` 给系统界面进程，附带自己的回调 Binder、包名、实现的协议版本（客户端库自动做）。
2. 岛回调 `onSessionReady(session, 岛的协议版本)`。接入库要求宿主通信版本至少为5。
3. **接入方必须在会话上调一次 `bind()`。** 岛按调用方 uid 核对你注册时自报的包名，通过后会话才生效；不通过时 `bind()` 返回false，客户端进入拒绝状态。没 `bind()` 的会话所有投送返回 `RESULT_INVALID`。客户端库自动做这一步。
4. 之后每次调用岛都再核一次调用方 uid，冒用别人包名的会话投不了内容、也收不到别人的事件。

## 二、内容项模型

每个内容项是一份 Bundle，由接入方用 `ActivityBundle.encode*` 拼装。字段约定：

- `id`：接入方内唯一，最长 128 字，超出截断。相同 id 的 `start` 视为整份替换。
- `kind`：只能从 `CUSTOM`、`LIVE_UPDATE`、`MEDIA`、`MESSAGE`、`TIMER` 里选；其它值一律按 `CUSTOM` 处理（`CALL`、`FACE_UNLOCK` 等是岛内置专属）。
- 展开模板（`expanded.template`）：外部来源可用 `GENERIC`、`MESSAGE`、`TIMER`、`PROGRESS`、`STATUS`、`MEDIA`、`HERO`、`CUSTOM`。`CALL` 模板外部来源不能用，声明了会被岛强制降为 `GENERIC`。
- `priority`：0 到 100，缺省等于种类的默认优先级；外部来源的实际上限为 80，超过压到 80。`exclusive` 外部来源无法声明为 true。
- `staleAtWallMs`：可选。到点后岛不再主动提醒，排位时排到末尾。**它不会移除内容项**。
- `dismissAfterMs`：可选。缺省表示「来源结束时消失」（你调 `end`、你的进程死亡、或 8 小时上限）；大于 0 表示最后一次更新后过这么多毫秒自动移除；**等于 0 表示立即移除**。
- `accentColor`：可选。岛会检查它在纯黑底色上的可读性，过暗时保留色相并提亮。
- `openIntent`：可选。用户点击展开卡片的空白处时触发。
- `hideWhenSourceForeground`：缺省为 true。接入方 App 在前台时，内容项自动退到副岛。
- 文本上限：全部文本字段加起来不超过 8 KB（UTF-8），单字段另有上限：id 128 字、标题 128 字、副标题 256 字、正文 4096 字、歌词行 512 字、按钮文字 32 字、胶囊文字 512 字、读屏描述 256 字。超限时截断，不丢内容项。图片不计入文本。
- 展开卡片按钮最多 3 个，多出的丢弃。
- **来源标识：** 外部来源的展开卡片副标题前面由岛自动加上「来自 <你的应用名> · 」，用户能分辨内容是谁投的，接入方不用也不能去掉。

### 图标限制（外部来源）

- `builtin`：岛自带的矢量图标，随便用。
- `app`：只能指向你自己的包名。指向别的包被拒。
- `platform`（系统 `Icon` 对象）：外部来源一律拒绝，因为岛会用系统界面的身份去读它指向的资源。
- `bitmap`：任一边超过 2048 像素、或字节数超过 8 MB 的位图被拒。

图标被拒时只丢那一个图标，内容项照常上屏，返回值为 `RESULT_ICON_REJECTED`。

胶囊与展开卡片的排版由宿主统一控制。文字能否放下按用户设置的最大宽度及身份区、信息区的实际可用空间判断；允许滚动且放不下时连续滚动。主岛图标固定在身份区起点，名称在余下空间居中。

### 收尾画面（Outro）

`end(id, outro)` 的 `outro` 参数可空。携带时（Bundle，键 `success` / `text`），岛移除该内容项后在胶囊上短暂显示打勾（成功，绿）或叉号（失败，红）与一句话，1.6 秒后自动消失。收尾画面不占同时内容项配额，但 `end` 计入每秒 10 次的频率限制，且同样受权限与来源开关约束。收尾画面不回传事件，`listMine()` 也不列出它。

## 三、返回结果码

`start` / `update` / `end` 返回 int，含义固定：

| 值 | 常量 | 含义 |
|---|---|---|
| 0 | `RESULT_OK` | 已受理；可能等待合并或排位，不等于已经显示 |
| 1 | `RESULT_NO_PERMISSION` | 来源未获得声明的接入权限 |
| 2 | `RESULT_SOURCE_DISABLED` | 用户在来源管理里关掉了你 |
| 3 | `RESULT_KIND_DISABLED` | 用户关掉了这个内容种类 |
| 4 | `RESULT_QUOTA_EXCEEDED` | 同时内容项已满 3 个 |
| 5 | `RESULT_RATE_LIMITED` | 每秒超过 10 次 |
| 6 | `RESULT_ICON_REJECTED` | 已受理，但有图标因超限或来源不符被丢弃 |
| 7 | `RESULT_INVALID` | 内容无效（缺 id、收尾画面缺文字）或会话没绑定 |
| 8 | `RESULT_BUSY` | 岛主线程两秒内没处理这次调用，稍后重试 |
| 9 | `RESULT_NOT_CONNECTED` | 只在客户端侧出现：没有会话或跨进程调用失败 |
| 10 | `RESULT_CUSTOM_REJECTED` | 自绘图片、点击区域或动作关联无效，未替换现有内容 |

`update` 与 `start` 语义完全相同，只为兼容保留，已标记为废弃；新代码一律用 `start`。

`listMine()` 返回当前登记且未结束的内容项 id（包含等待排位的内容，不代表全部正显示在屏幕上） 列表，断线重连后用来对账，不用盲投。

## 四、事件回传

版本5的 `IIslandClient` 为单向回调，来源不返回处理结果。来源卡住不会让系统界面等待，操作是否真正完成仍由来源后续更新内容确认。

岛通过 `IIslandClient` 回调向接入方回传事件。事件是「尽力送达」，接入方不能把它当作业务依据；断线重连后用 `listMine()` 重新同步状态。

| 事件 | 触发时机 |
|------|---------|
| `onSessionReady` | 岛把会话交给你，附带岛的协议版本；客户端库随后自动 `bind()` |
| `onSessionLost` | 绑定被拒，或岛主动停用（总开关关闭、熔断） |
| `onAction` | 用户点了展开卡片里的按钮 |
| `onExpanded` | 岛展开 |
| `onCollapsed` | 岛收起 |
| `onDismissedByUser` | 保留字段，当前版本岛不会发出（主岛不提供上滑删除）；内容项只会因你 `end`、用户清通知、开关或到期结束 |
| `onPromoted` | 用户点了副岛，内容项提到主岛 |
| `onDemoted` | 内容项被更重要的内容项挤到副岛 |
| `onExpired` | 内容项因 `dismissAfterMs` 到点、或达到 8 小时活跃上限被岛移除（**不是** `staleAtWallMs`） |
| `onEndedBySystem` | 内容项因用户关掉来源 / 关掉种类、岛被关闭等原因被移除 |

回传参数统一为 `activityId`、`eventName`、`timestampMs`。

岛进程（系统界面）崩溃或重启时不会有 `onSessionLost`：客户端库对会话做了死亡监听，会自动回调 `onReadyChanged(false)`，并在收到岛重启广播后自动重新注册。

## 五、锁屏与读屏

- `lockScreenVisibility`：三档，缺省 `PUBLIC`。
  - `PUBLIC`：锁屏照常显示。
  - `REDACTED`：锁屏只显示标题：胶囊里的文字槽位清空（图标保留），展开卡片只剩标题，副标题、正文、歌词、按钮全部隐藏。
  - `PRIVATE`：锁屏完全隐藏，不参与排位；解锁后恢复。
- `contentDescription`：可选，最长 256 字。给安卓读屏功能用的描述文字，一句话说明当前内容项。缺省时读屏读展开卡片的标题。

## 六、版本与稳定性承诺

通信版本为 `protocolVersion`（当前5），代码常量为 `ActivityBundle.PROTOCOL_VERSION`。清单中的 `manifestFormat` 只表示清单文件格式，与通信版本无关。

- Bundle 键名只加不删，不认识的键一律忽略。
- 已有键的类型与语义不变。
- 新增事件或改 AIDL 方法签名时协议版本加一。
- 版本5使用单向回调。`onSessionReady` 与 `session.getProtocolVersion()` 提供宿主版本；本接入包要求宿主至少为5。

## 七、自绘卡片（协议版本5）

接入方在自己的进程里画完整位图，使用 `CUSTOM` 展开模板，经 `expanded.hero` 的 `bitmap` 图标格式传入。岛不执行接入方代码，不加载接入方布局、远程地址或任意文件。身份检查、来源开关、提醒冷却、内容项数和更新频率仍与普通模板一致。

- 每边最多2048像素，实际分配内存最多8MB，图片必须未回收。超限或缺失图片会拒绝整个自绘内容项，不显示空白假卡。
- 岛在图外保留来源标识，图片和点击区域不能覆盖该标识。
- `expanded.customRegions` 是最多3项的Bundle列表。每项含 `actionId` 与 `left/top/right/bottom` 四个浮点数，表示图片内0至1的比例坐标。
- 坐标必须为有限数值、在0至1内、矩形宽高大于0；各区域不得重叠。每个区域必须对应 `expanded.actions` 内唯一的动作，动作有非空名称；不能声明没有区域的隐藏动作。
- 点击区域通过既有 `onAction(activityId, actionId)` 返回来源，由来源更新位图或执行操作。读屏名称来自该动作的label；图片本身的内容说明由contentDescription提供。接入方自行绘制大字体版本，岛不能重新排版位图里的文字。
- 岛按实际显示大小检查触摸范围；过小区域对应的操作移到图片下方的具名按钮，不要求用户点击极小区域。
- `REDACTED` 锁屏时清除自绘图片、区域和动作，只保留标题；`PRIVATE` 完全隐藏。
- 无效图片、区域或动作关联返回 `RESULT_CUSTOM_REJECTED=10`。不更新现有卡片，来源可以保留上一份有效内容并说明错误。
- 客户端必须先确认岛协议版本至少5。
- Android 31以上客户端把位图转换为不可变共享位图再传送，减少跨进程传输体积；仍遵守大小与更新限制。根据[安卓位图说明](https://developer.android.com/reference/android/graphics/Bitmap#asShared())，共享位图适合进程间传递；[跨进程传输限制](https://developer.android.com/reference/android/os/TransactionTooLargeException)说明单次大数据仍可能失败，客户端必须处理失败结果。

这是一种“自绘内容＋声明操作区域”的接入方式，不提供第三方任意视图、脚本或输入控件的执行能力。样例会实际绘图，点击图内按钮后重新绘制并更新内容。

## 八、客户端库与样例

客户端以AAR提供，包名 `com.astraisland.client`，最低系统版本26，编译目标36。示例展示连接、投送、更新、自绘及结束操作。

接入方使用版本化的库和公开清单，不自行修改库内通信定义。

## 九、协议清单文件

本协议的Bundle键名、结果码和上限由公开包的 `protocol/island-protocol.v1.json` 记录。接入方以所用发布版本附带的清单为准。

## 星流内置宿主

星河岛能力由星流安装包完整提供，独立星河岛应用已停止发布。接入库发现带 `com.astraisland.HOST_PROTOCOL` 元信息的星流正式／调试包，并兼容已安装的旧版独立星河岛，由库清单合并各宿主对应的投送权限和包查询。系统界面中按实际运行状态只保留一个岛服务，普通通信字段和版本5保持不变。

接入库1.1.0起同时发现星流与旧版独立星河岛；旧接入库1.0.0只查找独立星河岛。星流权限定义使用自身包名，避免两款应用安装时争用同名权限。
