# 星河岛 SDK 示例工程

本工程演示如何使用星河岛 SDK 0.1.0 将内容显示在星河岛上。

## 运行环境

- Android Studio（Android Gradle 插件 8.9 及以上）、JDK 17。
- 测试设备需安装星流（Android 15 及以上）并启用星河岛；OPPO、一加、realme 手机上还需安装并启用星流官方插件「流体云事件接入」。

## 使用方法

1. 将 `astraisland-sdk-0.1.0.aar` 放入 `app/libs` 目录（下载包中已放好）。
2. 用 Android Studio 打开本目录，同步后运行 `app`。
3. 点击「连接星河岛」，状态显示为 `READY` 后，依次点击各按钮查看九种卡片。

## 内容说明

- `MainActivity.kt`：连接星河岛，逐一显示通用、进度、强调（取件码与倒计时）、明细、状态、大图、音乐、消息、对称九种卡片，演示文字按钮、圆形图标按钮、底部图标按钮、开关按钮、计时控制与音乐按键，以及收尾、回复、拖动进度、划走与结束回调。
- `ApiExamples.kt`：接口说明中的三个示例（下载进度、可回复的消息、倒计时）。
- `JavaExample.java`：Java 调用示例。

`start`、`update`、`end`、`endAll`、`listMine` 会等待星河岛处理完毕后返回，示例均在后台线程调用；回调在主线程执行。
